# 🏦 Banking Management System

A simple **Banking Management System** built with **Python and Streamlit** that allows users to create and manage bank accounts through a web-based interface.

The project demonstrates **Object-Oriented Programming, file handling, data persistence, validation, authentication, and Streamlit UI development**.

---

## 🚀 Features

- 📝 Create a new bank account
- 🔐 Account login using account number and PIN
- 💰 Deposit money
- 💸 Withdraw money
- 👤 View account details
- 📝 Update account information
- 📊 View transaction history
- 🗑️ Delete bank account
- 💾 Persistent data storage using JSON
- ✅ Input validation
- 🔄 Automatic balance updates
